01 / ABOUT

가르치며 배우는
교육자, 용쌤

초등학생을 대상으로 드론·항공과학과 코딩을 가르치고 있습니다. 대학에서는 데이터와 인공지능 관련 공부를 이어가며, 배운 내용을 교육 현장과 연결하고자 합니다.

수업에서 중요하게 생각하는 것은 안전, 집중, 문제해결과 협력입니다. 작은 성공을 쌓고 스스로 다시 도전할 수 있는 수업을 만들고자 합니다.

02 / TEACHING

수업으로 연결하는 탐구

대표 수업의 주제와 구성 방향을 소개합니다.

FLIGHT / 비행

드론 배터리와 안전

드론을 날리기 전에 장비를 살피고, 배터리를 안전하게 사용하는 방법을 배우는 수업입니다.

수업 구성 보기

배터리 표시 관찰 → 전압 확인과 관리 방법 → 비행 전 점검 → 상황별 안전수칙 확인 순서로 구성합니다. 실제 장비를 관찰하며 안전한 사용 습관을 기릅니다.

CODE / 코딩

순차·반복 코딩 기초

명령을 순서대로 실행하고 같은 동작을 반복하며, 코딩의 기본 구조를 익히는 수업입니다.

수업 구성 보기

생활 속 순서 찾기 → 명령 배열 → 드론 동작 예상 → 실행 결과 관찰 순서로 진행합니다. 예상과 결과가 다른 이유를 찾아 명령을 수정해 봅니다.

ROBOT / 탐구

땅 위의 무인이동체 UGV

무인지상차량의 뜻과 이동 방식을 배우고, 카메라가 있는 교구의 부품을 관찰하는 수업입니다.

수업 구성 보기

UGV의 의미와 사례 → 바퀴·궤도 등 이동 방식 → 원격조종과 자율주행 구분 → 전원을 끈 교구의 부품 관찰로 구성합니다. 관찰 활동 후 조종 학습으로 이어갑니다.
